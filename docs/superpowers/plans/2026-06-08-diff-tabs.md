# Diff Tabs + Split-as-Default Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Run `npm run lint:fix` after each change and `npm run lint` + `npm test` before committing. Honor the `ToolResult` contract and the `@/*` alias sync rule from `AGENTS.md`.

**Goal:** Make **split** the default Diff output layout, and let the Diff tool hold **multiple independent comparison tabs** that persist across restarts. Diff `mode` (line/word/char) and `view` (inline/split) become global, persisted settings shared by all tabs.

**Architecture:** Add a `diff` slice to the single Zustand store (`tabs[]`, `activeTabId`, `nextSeq`, `mode`, `view`). Persist it as one storage key `"diff"` via the existing boot-hydrate + `subscribe`-save wiring in `src/App.tsx`. Extract the tab strip into a focused `DiffTabs.tsx`; refactor `DiffTool.tsx` to bind editors/output to the active tab and drop `useToolInput`. `diff.ts` (pure transforms) is unchanged.

**Tech Stack:** Existing only (React 18, TS, Tailwind v4, Zustand, Tauri 2, `@codemirror/merge`, Vitest + Testing Library). No new dependencies. `id` generation uses `crypto.randomUUID()`.

> **Source spec:** `docs/superpowers/specs/2026-06-08-diff-tabs-design.md`. **Mockup:** `docs/superpowers/mockups/diff-tabs-mockup.html`.

> **Out of scope (do NOT build):** per-tab mode/view, tab rename / reorder / content-derived labels, a hard tab cap, generalizing tabs to other tools, any change to `diff.ts` or the transform pipeline.

## Task 1: Add the `diff` slice + actions to the store

Centralize tabs and global toggles so the UI and persistence layer share one source of truth.

**Files:** Modify `src/core/store.ts`, `src/core/store.test.ts`.

- [ ] **Step 1: Types + default slice.** In `store.ts` add (importing `DiffMode` from `@/tools/diff/diff`):

```ts
export interface DiffTab { id: string; label: string; a: string; b: string }
export type DiffView = "inline" | "split";
export interface DiffSlice {
  tabs: DiffTab[];          // invariant: length >= 1
  activeTabId: string;      // always references an existing tab
  nextSeq: number;          // monotonic; powers labels
  mode: DiffMode;
  view: DiffView;
}

export function makeDefaultDiffSlice(): DiffSlice {
  const id = crypto.randomUUID();
  return { tabs: [{ id, label: "Diff 1", a: "", b: "" }], activeTabId: id, nextSeq: 2, mode: "line", view: "split" };
}
```

- [ ] **Step 2: State + actions.** Add `diff: DiffSlice` to `AppState` and initialize with `makeDefaultDiffSlice()`. Add action signatures and implementations:
  - `addDiffTab()` — append `{ id: crypto.randomUUID(), label: "Diff " + nextSeq, a: "", b: "" }`, `nextSeq + 1`, set `activeTabId` to the new id.
  - `closeDiffTab(id)` — if `tabs.length === 1`, no-op. Else remove it; if it was active, set `activeTabId` to the previous tab (or next when removing index 0).
  - `setActiveDiffTab(id)`.
  - `setDiffTabSide(id, side: "a" | "b", text)` — immutably update only that tab/side.
  - `setDiffMode(mode)`, `setDiffView(view)`.
  - All mutate via `set((state) => ({ diff: { ...state.diff, ... } }))`.

- [ ] **Step 3: Extend `hydrate`.** Add `diff` to the `hydrate` parameter `Pick`. In the `hydrate` impl, when a `diff` slice is supplied, **validate/repair** before applying: if `tabs` is missing/empty, use `makeDefaultDiffSlice()`; if `activeTabId` matches no tab, set it to `tabs[0].id`.

- [ ] **Step 4: Store tests** (`store.test.ts`): update `beforeEach` reset to include `diff: makeDefaultDiffSlice()`. Cover: `addDiffTab` appends + activates + bumps `nextSeq`; `closeDiffTab` removes and keeps `length >= 1` (no-op at one tab); closing the active middle tab activates a neighbor; labels unchanged after a middle close; `setDiffTabSide` updates only the target; `hydrate` repairs a stale `activeTabId`.

- [ ] **Step 5:** `npm run lint:fix` && `npm test`.

## Acceptance Criteria (from spec)

1. Diff opens in **split** layout by default.
2. Tab strip visible with ≥1 tab; `+` opens independent comparisons.
3. Each tab keeps its own Original/Changed text; switching swaps editors + output.
4. Closing never leaves zero tabs; close control hidden at one tab.
5. Labels do not renumber when an earlier tab is closed.
6. Tabs, active tab, and global mode/view survive restart.
7. `npm run lint`, `npm test`, `npm run build` pass; `diff.ts` unchanged.
